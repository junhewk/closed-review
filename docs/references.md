# References

Sources the project and the skill's design profiles refer to. Each DOI was checked against its
Crossref record (the arXiv preprint against arXiv). In a review, the skill labels these sources
`model_lead` unless the reviewer supplies them, and never attributes content to them from memory as
if checked.

## Project background

- Jayaram R, Tyler D, Woodruff D, et al. 2026. Towards automating scientific review with Google's Paper
  Assistant Tool. arXiv:2606.28277. [doi:10.48550/arXiv.2606.28277](https://doi.org/10.48550/arXiv.2606.28277)
- Jayaram R, Cohen-Addad V. 2026. Analyzing technical documents with Deep Review. Google Research blog,
  14 October 2026. <https://research.google/blog/analyzing-technical-documents-with-deep-review/>

The scan's segment-based structure follows this work. The preprint describes the Paper
Assistant Tool (PAT), and the blog post presents Deep Review as its public successor; closed-review
runs the structure on a self-hosted model and adds its own enforced checks.
